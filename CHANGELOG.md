# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-11-05

### Added

- Initial public release candidate: fail-closed audit guard engine.
- Rule data (red lines / fence / permission matrix) as JSON, not code.
- Hash-chained, offline-verifiable audit trail.
- 23 unit tests with zero third-party dependencies.
- stdio JSON-lines semantic layer (`audit.call` / `audit.resolve` / `audit.pending`).
